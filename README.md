## 🌟 المميزات الرئيسية

هذا المشروع ليس مجرد موقع تعريفي، بل هو **تطبيق ويب تقدمي (PWA)** وعيادة رقمية متكاملة تقدم الميزات التالية:

1. **🏥 واجهة مستخدم فاخرة (Premium UI):**
   - تصميم يعتمد على ألوان متناسقة تناسب المجال الطبي الراقي.
   - حركات تفاعلية سلسة (Animations) بفضل Framer Motion.
   - دعم كامل للشاشات الصغيرة والمتوسطة والكبيرة (Fully Responsive).

2. **🤖 المساعد الطبي الذكي المدمج (AI Triage):**
   - مساعد طبي يعتمد على الذكاء الاصطناعي (Gemini 2.0).
   - يقوم بـ **الفرز الطبي (Triage)** عبر محادثة نصية مع المريض.
   - قادر على التعرف على الحالات الحرجة وتوجيه المريض فوراً للطوارئ.

3. **📱 تطبيق الشاشة الرئيسية (PWA):**
   - الموقع قابل للتثبيت على هواتف الأندرويد والآيفون كتطبيق مستقل.
   - ملف `manifest.json` مخصص مع أيقونات متعددة الأحجام.

4. **🔒 لوحة تحكم إدارية (Admin Dashboard):**
   - محمية بالكامل بنظام تسجيل دخول آمن خلف مسار `/dashboard`.
   - إدارة الرسائل الواردة وطلبات المواعيد في الزمن الفعلي.
   - التحكم بعرض وإخفاء الفيديوهات التثقيفية وحالات المرضى.
   - إدارة حالة وإعدادات المساعد الذكي.

## 🛠 البنية التقنية (Tech Stack)

تم تطوير هذا النظام باستخدام أحدث تقنيات الويب العالمية:

- **إطار العمل الأساسي:** [Next.js 14](https://nextjs.org/) (App Router)
- **لغة البرمجة:** [TypeScript](https://www.typescriptlang.org/) (لضمان خلو الكود من الأخطاء)
- **التصميم وتنسيق الواجهات:** [Tailwind CSS](https://tailwindcss.com/)
- **الأنميشين:** [Framer Motion](https://www.framer.com/motion/)
- **قاعدة البيانات والاستضافة الخلفية:** [Supabase](https://supabase.com/) (PostgreSQL)
- **إدارة الحالة (State Management):** React Hooks & Context API
- **الذكاء الاصطناعي:** Vercel AI SDK مع Google Gemini
- **الأيقونات والرسوميات:** [Lucide React](https://lucide.dev/)

## 🗄️ هيكل قاعدة البيانات (Database Schema)

يعتمد التطبيق على الجداول التالية في Supabase:

- `appointments`: لتسجيل وحفظ طلبات الحجز الطبية.
- `contacts`: لحفظ رسائل الزوار العادية والتواصل المباشر.
- `testimonials`: لحفظ وعرض آراء المرضى (بموافقة الدكتور).
- `videos`: روابط مقاطع الفيديو التثقيفية والعمليات (يوتيوب).
- `settings`: جدول ديناميكي لتغيير إعدادات الموقع فورياً (כاسم الدكتور، رقم الهاتف، نصوص الترحيب للـ AI).

## 🔐 الأمان والخصوصية (Security & Privacy)

نظراً لحساسية البيانات الطبية، تم تنفيذ الطبقات الأمنية التالية:

1. **جدار الحماية (Row Level Security - RLS):**
   - أوامر RLS مفعلة في Supabase لمنع وصول أي مستخدم للبيانات ما عدا الحساب الإداري الموثق للطبيب.
   
2. **تنظيف المدخلات (Input Sanitization):**
   - حماية كاملة ضد هجمات XSS. لا يمكن إرسال أي سكربت ضار عبر نموذج الاتصال.
   
3. **مكافحة البريد المزعج (Rate Limiting):**
   - إيقاف مؤقت لأي IP يحاول إرسال رسائل أو طلبات مواعيد بشكل متكرر ووهمي.

## ⚙️ خطوات التشغيل المحلي (Installation)

إذا كان لديك صلاحية لتعديل الكود، اتبع الخطوات التالية:

### 1️⃣ المتطلبات المسبقة
يجب أن يكون لديك [Node.js](https://nodejs.org/en/) (إصدار 18 أو أحدث) منفذ الأوامر المثبت على جهازك.

### 2️⃣ التثبيت
```bash
# استنساخ المستودع (يتطلب صلاحيات الوصول)
git clone https://github.com/phantome001/surgeon-portfolio.git

# الدخول للمجلد
cd surgeon-portfolio

# تثبيت الحزم والمكتبات
npm install
```

### 3️⃣ المتغيرات البيئية (Environment Variables)
قم بإنشاء ملف `.env.local` في جذر المشروع وضع فيه المفاتيح التالية (احصل عليها من Supabase و OpenRouter):
```env
NEXT_PUBLIC_SUPABASE_URL="https://YOUR_PROJECT_ID.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="YOUR_SUPABASE_ANON_KEY"
SUPABASE_SERVICE_ROLE_KEY="YOUR_SUPABASE_SERVICE_KEY"

GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
OPENROUTER_API_KEY="YOUR_OPENROUTER_API_KEY"

ENCRYPTION_KEY="مفتاح سرِّي مكوّن من 32 حرفاً لتشفير البيانات"
```

### 4️⃣ التشغيل والتشخيص
```bash
npm run dev
```
👉 افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## 🚀 النشر (Deployment)

هذا التطبيق مُحسّن ومجهز للنشر بنقرة واحدة على شبكة **Vercel**. 
تطبيق Next.js يتوافق بشكل خرافي مع استضافة Vercel التي ستوفر (Edge Functions) لعمل المساعد الذكي بأسرع وقت، مع دعم تلقائي للصور وتحسين سرعة استجابة الموقع.
